# Synthetic Staging Rules - Tech and Fragile Goods

- R-021: Tech orders including calibration strips and glass accessories require anti-shock packaging mode.
- R-022: If order contains instrument sleeves with premium devices, attach FRAGILE_VISIBLE label set.
- R-023: White-glove shipping for tech requires two-step packing verification event PACK_VERIFY_DUAL.
- R-024: Overnight tech shipments automatically upgrade to tamper seal profile SECURE_TAMPER_1.
- R-025: If tech item quantity exceeds 20 units, split into carton batches of maximum 10 units each.
